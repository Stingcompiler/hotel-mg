# API contract — `v1.0-api`

Frozen at the API freeze (spec §12). The frontend is built against these files only.

| File | What |
| --- | --- |
| `openapi.yml` | OpenAPI 3 schema generated by drf-spectacular from the Django code |
| `schema.d.ts` | TypeScript types generated by `openapi-typescript` (used by the F1 API client) |
| `skytowers.postman_collection.json` | Postman v2.1 collection (also imports into Bruno) |

CI job **api contract** regenerates all three and fails when they differ from what is committed.
`api/VERSION` holds the contract version; when it changes on `main`, the **API tag** workflow tags that commit
`v<version>-api`.

## Regenerate after an API change

```bash
cd server && python manage.py spectacular --validate --fail-on-warn --file ../api/openapi.yml
cd ../api && npm ci && npm run gen
cd .. && python build/postman_collection.py
```

After the freeze, changes are additive only (new endpoints or optional fields). A breaking change needs a
decision in `docs/decisions.md` and a new tag.
