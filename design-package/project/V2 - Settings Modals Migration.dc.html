يُفعَّل بعد اكتمال القائمة
قرارات الإصدار 2 (اتُّخذت نيابةً عنك)
• الانحرافات الأربعة عن البريف مُعتمَدة كما بُنيت: صف سريع + درج للمصروف (كلاهما)، لوحة يمنى للنزيل، تعديل inline لقواعد التنبيه، إجراءات الحجوزات للصف المحدد فقط. السبب المشترك: أقل انتقالًا وأقل ضجيجًا لموظف واقف.
• الإعدادات الثلاثة الباقية تتبع النمط نفسه (قائمة يمنى + جدول inline). سجل التدقيق للقراءة فقط بصيغة «قبل ← بعد» ومرجع LTR.
• تغيير الغرفة: نفس النوع = فرق صفر ولا موافقة؛ اختلاف النوع بفرق سالب يطلب المدير. الإلغاء: زر خطر بنص يذكر مبلغ الردّ صراحةً، وثلاث طرق للتسوية مثل المدة المختلطة في 6.4.
• تقرير واحد إضافي (الوصول والمغادرة) يثبت أن قالب التقرير يغطي البقية: بلاطات ≤ 3 + جدول + سطر معادلة/ملاحظة + PDF/Excel/CSV ثانوية.
• الترحيل الأولي: أربع خطوات (الغرف والأسعار ← المستخدمون ← الإقامات الجارية ← الفتح الرسمي)؛ الأرصدة السابقة قيد «رصيد مُرحَّل» خارج الورديات، والفتح الرسمي لا يُعكس.
